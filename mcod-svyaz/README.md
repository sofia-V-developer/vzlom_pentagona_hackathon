# МЦОД Связь

Симулятор для кейса ООО «Датарк» о мобильной связи внутри МЦОД. Он сравнивает покрытие до и после включения репитера, рассчитывает DL и UL в выбранной точке и показывает, когда срабатывает модельная защита GSM-канала аварийных SMS.

В интерфейсе два МЦОД и семь сценариев, включая ухудшение изоляции, отказ фильтра и потерю донорного сигнала. Настройки и события сохраняются в SQLite. Расчёт можно выгрузить в Markdown, JSON или открыть для печати.

## Запуск в Docker

Из корня проекта:

```bash
docker compose up --build
```

Откройте [МЦОД Связь](http://127.0.0.1:8000/). База сохраняется в томе `mcod-data`. Для повторного запуска готового образа без обращения к реестру используйте `docker compose up --no-build`.

## Запуск без Docker

Нужны Python 3.12 и Node.js 22. Установка зависимостей и первая сборка требуют доступ к PyPI и npm. Готовый стенд работает локально без интернета.

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements-dev.txt
npm --prefix frontend ci
npm --prefix frontend run build
PYTHONPATH=backend .venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте [главный экран](http://127.0.0.1:8000/). SQLite создаётся в `data/mcod.sqlite3`. Переменная `MCOD_DB` задаёт другой путь к базе.

Для разработки интерфейса оставьте backend на порту 8000 и выполните `npm --prefix frontend run dev`. Vite проксирует `/api` на backend.

## Первый показ

1. Выберите **МЦОД Север** и **Штатная работа**. Для чистого прогона нажмите **Сбросить**.
2. Сравните **До** и **После**. При штатных параметрах 43,8% свободной площади проходят порог DL −105 dBm, а 8,5% проходят одновременно DL и UL. В аппаратном зале эти доли составляют 58,3% и 12,7%.
3. Выберите точку на плане и откройте **Бюджет DL / UL**. Покажите, как уровень в телефоне и запас на БС рассчитываются отдельно.
4. Выберите **Недостаточная изоляция**. Нажмите **Следующий шаг** три раза. На первом шаге модель ограничит усиление, на третьем отключит ретрансляцию.
5. Откройте **Оборудование и отчёт** и выгрузите снимок. Чтобы снова включить штатную ретрансляцию, выберите **Штатная работа** и нажмите **Сбросить защиту**.

Пошаговый [сценарий защиты на 3–5 минут](docs/demo_script.md).

## Проверки и API

```bash
PYTHONPATH=backend .venv/bin/python -m pytest -q backend/tests
npm --prefix frontend run typecheck
npm --prefix frontend run build
curl -fsS http://127.0.0.1:8000/api/v1/health
curl -fsS http://127.0.0.1:8000/api/v1/sites/north/snapshot
```

[Спецификация OpenAPI](http://127.0.0.1:8000/api/v1/openapi.json). Операции и семантика снимков описаны в [архитектуре](docs/architecture.md). Запускайте один процесс Uvicorn на базу. Стенд рассчитан на локальный доступ без авторизации. Управление реальным RF-оборудованием отсутствует.

План «МЦОД Север» оцифрован по чертежу. Высота, размещение антенн, потери, канал Band 7 и пороги заданы для симуляции. Кейс приводит −110 dBm и хуже без указания метрики. Модель не использует это значение как измеренный RSRP. Для выводов об ЭМС, доставке SMS и голосовой связи требуются данные объекта, параметры модема и проверки на реальном оборудовании.
